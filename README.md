# Labia — Tú hablas, Labia escribe.

Dictado por voz para Windows. Mantén **Ctrl derecho**, habla y suelta: el texto aparece donde está
el cursor, en cualquier aplicación.

- **Privada:** tu voz se transcribe dentro de tu computadora con Whisper. El audio nunca sale de ella.
- **Rápida:** menos de un segundo por dictado con una tarjeta gráfica NVIDIA.
- **Gratis:** dictado ilimitado para siempre. Prueba de 7 días de **Labia Pro** (pulido con IA,
  vocabulario personalizado e historial completo), que después se compra con un pago único.

## Descargar

**[Descargar Labia para Windows](https://github.com/edgardavidperazaenriquez-png/labia/releases/latest/download/Labia-Setup.exe)**

Requisitos: Windows 10 u 11 de 64 bits y un micrófono. Recomendado: GPU
NVIDIA. Sin ella, Labia usa automáticamente un modelo más ligero que funciona en cualquier
procesador moderno.

> Windows puede mostrar el aviso "Windows protegió su PC" porque el instalador es nuevo. Pulsa
> **Más información → Ejecutar de todas formas**.
